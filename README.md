# books

This folder contains the catalog page for the author’s published books and the downloaded PDF files.

## Project links

- GitHub repository: https://github.com/prakashbh/books
- GitHub Pages site: https://prakashbh.github.io/books/

## Structure

- `index.html` — main landing page for the book catalog
- `styles.css` — visual styling for the layout
- `script.js` — renders the book listing from `data/books.json`
- `data/books.json` — metadata for each published book
- `pdf/` — downloadable PDF files

## Notes

- The book page is designed to be easy to host on GitHub Pages.
- Each entry includes a short blurb, publication year, word count, page count, and direct PDF link.
- Replace the sample metadata with final publication details later if needed before pushing to the remote repository.
- After pushing to GitHub, enable GitHub Pages in the repository settings if it is not already active, and the site should be available at the URL above.
